# Компьютерный класс

> **Учителю:** простая инструкция — [ИНСТРУКЦИЯ для учителя.md](ИНСТРУКЦИЯ%20для%20учителя.md).

Приложение учителя для Mac и агент для Windows-ноутбуков учеников.
Полная инструкция для учителя появится на этапе 7. Пока здесь описано, как проверить текущий этап.

## Структура

| Папка | Что внутри |
|---|---|
| `teacher/` | приложение учителя: сервер, панель (`teacher/web`), mDNS |
| `agent/` | агент для Windows; всё, что зависит от Windows, — в `agent/platform/windows.py` |
| `shared/` | протокол (с версией) — общий для обеих сторон |
| `tools/` | фейковый агент для Mac, скрипт сборки agent.exe на Windows |
| `tests/` | тесты |
| `.github/workflows/` | сборка agent.exe в GitHub Actions |

## Что уже умеет (этапы 1–6)

- **Класс:** подключение ноутбуков кнопкой «Принять»; открыть сайт или **поиск** (просто напишите, что найти);
  наборы вкладок урока; «Внимание на учителя»; сообщение на весь экран; закрыть программу;
  выключить/перезагрузить с отсчётом 30 секунд и кнопкой «Отменить». Всё — «всем» или «выбранным».
- **Сбор проектов:** агент следит за «Загрузками» и «Рабочий стол\Проекты» (список — в «Настройках»),
  отправляет новые файлы на Mac с проверкой SHA-256 и докачкой; если Mac выключен — файлы ждут.
  Файлы, лежавшие на ноутбуке до установки агента, не отправляются и не удаляются.
- **Сортировка:** «Проекты» → создайте группу, добавьте учеников (с вариантами написания), выберите
  «Сейчас занимается». Файлы с именем ученика попадут в `Проекты/<Группа>/<Имя>/<дата>/`, остальные —
  в «Неразобранное», где их можно назначить одним кликом.
- **Яндекс Диск:** «Настройки» → «Яндекс Диск» — пошаговая инструкция получения токена.
- **Материалы урока:** «Класс» → «Отправить материалы» → выберите файлы или папки → «Отправить».
  Ноутбуки скачивают их параллельно, с докачкой и проверкой SHA-256, в `Рабочий стол\Материалы`
  (папка меняется в «Настройках»). Выключенный ноутбук получит материалы при подключении (в течение суток).
  Эта папка не собирается как проекты и не очищается «Концом урока».
- **Конец урока:** зелёная кнопка — собрать всё → дождаться подтверждения каждого файла →
  очистить папки (файлы уходят в корзину агента `%LOCALAPPDATA%\ClassroomAgent\trash` на 7 дней).
  Если хоть один файл не получен, на этом ноутбуке ничего не удаляется.

## Обновления агентов (автоматически)

При каждой сборке в ветке `main` GitHub публикует подписанный релиз `agent-vX.Y.Z`
(если версия в `agent/__init__.py` новая). Приложение учителя раз в час проверяет релизы, скачивает
новую версию, проверяет цифровую подпись и раздаёт её ноутбукам по локальной сети.
Ноутбук обновляется, только когда на нём нет заставки, сообщения, отсчёта выключения и отправки файлов.
Если новая версия не запустится за 30 секунд — ноутбук возвращает прежнюю. Откат на старую версию запрещён.

**Ключ подписи.** Закрытый ключ хранится в секрете GitHub `AGENT_SIGNING_KEY` и в файле
`~/Library/Application Support/ClassroomTeacher/agent-signing-key.txt` (резервная копия — держите её
ещё и в менеджере паролей). Открытый ключ — в `shared/update.py`. Если закрытый ключ потерян: создать новый
(`tools/make_signing_key.py`), заменить открытый ключ и один раз обновить ноутбуки вручную.

## Приложение «Айтишкино» для учителя

**Windows (админский ноутбук):** скачать `Aitishkino.exe` из релиза `teacher-v*`
(https://github.com/RuslanGiaurgiev/classroom/releases/download/teacher-v1.0.0/Aitishkino.exe) и запустить.
Панель открывается в браузере, приложение показывает окно управления. Сборку делает CI (GitHub Actions),
исходники внутри скомпилированы. Версия — в `teacher/__init__.py`.

### Приложение на Mac (этап 7)

Создать значок в «Программах» (один раз, ничего не скачивается):

```bash
.venv/bin/python tools/make_mac_app.py
```

Дальше «Айтишкино» запускается из «Программ», Launchpad или Dock (правый щелчок → «Параметры» →
«Оставить в Dock»). Внутри .app — только маленький загрузчик. Рабочая копия программы и библиотеки лежат в
`~/Library/Application Support/Aitishkino` (скопированы из этой папки и `.venv`, без интернета) — поэтому
приложению не нужен доступ к Рабочему столу, а правки в папке проекта не мешают рабочей версии.
При первом запуске macOS спросит доступ к папке «Документы» (там «Компьютерный класс») — разрешите.

- При каждом запуске приложение подтягивает обновления с GitHub и доустанавливает библиотеки, если изменился
  `requirements-teacher.txt`. Без интернета — просто запускается.
- Журнал запуска: `~/Library/Logs/Айтишкино.log`; журнал работы — в
  `~/Library/Application Support/ClassroomTeacher/logs/teacher.log`.
- Повторный запуск просто показывает открытое окно; ⌘Q — выход.
- Запасной способ: двойной щелчок по «Запустить учителя.command».

**Место на Mac.** Работы, отправленные на Яндекс Диск, удаляются с Mac автоматически — но только после
проверки: контрольная сумма файла на Диске должна совпасть с полученным с ноутбука. В «Работах» такие
файлы открываются кнопкой «☁️ На Диске». Выключается в «Настройки» → «Яндекс Диск» → «Место на Mac».

## Этап 1: как проверить

### На Mac (в Терминале, в папке проекта)

```bash
# тесты
.venv/bin/python -m pytest

# приложение учителя (откроется окно)
.venv/bin/python -m teacher.main
```

При первом запуске macOS может спросить:
- **«Разрешить Python принимать входящие подключения?»** — нажмите «Разрешить». Иначе ноутбуки не смогут подключиться.
- **«Разрешить находить устройства в локальной сети?»** — нажмите «Разрешить».

Если вы случайно нажали «Запретить», это исправляется в «Системные настройки → Сеть → Брандмауэр → Параметры» и в «Конфиденциальность и безопасность → Локальная сеть».

### Фейковые ноутбуки (без Windows)

Пока приложение учителя открыто, в **другом** окне Терминала выполните:

```bash
.venv/bin/python -m tools.fake_agent             # 11 ноутбуков
.venv/bin/python -m tools.fake_agent --count 3   # или 3
```

В панели появятся ноутбуки 1–11 со статусом «на связи». Чтобы самому нажимать «Принять», добавьте `--manual`. Команды, которые получают ноутбуки, печатаются в этот Терминал.
Ctrl+C останавливает фейковые ноутбуки, и в панели они становятся «не на связи».

### На настоящем ноутбуке

1. Скачайте `agent.exe` из GitHub Actions: Actions → последний запуск → Artifacts → `agent-windows`. Это zip, внутри него `agent.exe`.
2. Запустите `agent.exe` на ноутбуке, войдя под учётной записью ученика. Ничего вводить не нужно:
   агент сам найдёт Mac и покажет крупное двузначное число.
3. В панели учителя вверху появится «Новые ноутбуки просят подключения» с тем же числом.
   Введите номер с наклейки и нажмите «Принять».
4. На ноутбуке появится галочка ✓, а в панели ноутбук станет «на связи».

Если ноутбук долго пишет «Ищу компьютер учителя…», введите в его окне адрес Mac. Он показан в панели вверху справа, вводить только цифры, например `192.168.3.96`.

Windows SmartScreen может показать «Система Windows защитила ваш компьютер», потому что файл не подписан. Нажмите «Подробнее» → «Выполнить в любом случае».

Без GitHub agent.exe можно собрать на любом Windows-компьютере: установите Python 3.12 и запустите `tools\build_agent_windows.bat`.

Логи агента лежат в `%LOCALAPPDATA%\ClassroomAgent\logs\agent.log`, логи учителя — в `~/Library/Application Support/ClassroomTeacher/logs/`.
